# TaskMaster

Egyszerű webes feladatkezelő alkalmazás (szakdolgozat projekt).

## Elérhető
https://kovacsatti0831.github.io/TaskMaster/

## Funkciók
- Feladatok létrehozása, szerkesztése, törlése, teljesítése
- Prioritás és határidő alapú színkódolás
- Kategóriák, szűrés, rendezés
- Előzmények és statisztika
- Sötét / világos mód
- Reszponzív megjelenés (mobil + desktop)
- Random tipp funkció
- Local Storage adattárolás

## Technológia
- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage

## Futtatás
Nincs szükség telepítésre, elég megnyitni az `index.html` fájlt böngészőben, vagy a fenti linken keresztül.
